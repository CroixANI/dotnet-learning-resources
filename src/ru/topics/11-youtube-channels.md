# YouTube каналы

Каналы на которых можно почерпнуть много интересного по программированию и работе программиста

- [CS50 на русском (Гарвардский курс по основам программирования)](https://www.youtube.com/playlist?list=PLawfWYMUziZqyUL5QDLVbe3j5BKWj42E5)  
  Великолепная вводная в computer science.

- [АйтиБорода](https://www.youtube.com/channel/UCeObZv89Stb2xLtjLJ0De3Q)  
  Проект, посвящен не столько программированию, сколько жизни айтишников изнутри. Без всякой цензуры, ярлыков и лишнего пафоса.

- [Soer](https://www.youtube.com/c/S0ERDEVS)  
  На канале можно найти много познавательных видео по программированию, архитектуре и о жизни программиста. У автора есть еще второй канал [Soer Talks](https://www.youtube.com/channel/UCcNotjFXtUZ6bTAWk1KpOWg).

- [Хекслет](https://www.youtube.com/user/HexletUniversity)  
  Довольной интересный канал, особенно советую прослушать подкаст [Мысли и Методы](https://soundcloud.com/mimpod) либо посмотреть [плейлист](https://www.youtube.com/playlist?list=PLo6puixMwuSNBQPpzujzLWON2dwPbmJt_).

- [Технострим Mail.Ru Group](https://www.youtube.com/user/TPMGTU)  
  Образовательный канал для IT специалистов. Здесь можно найти курсы по программированию: БД, Java, Go, Python.

- [Степан Береговой](https://www.youtube.com/user/zaemiel)  
  Степан Береговой — программист C# на платформе .NET с опытом более 15 лет. На канале есть видео-курс [C# уроки для начинающих. С нуля!](https://www.youtube.com/playlist?list=PL9dWBtRq5J0KoaUcSmEaklxKTwGKAeU68).

- [Флант](https://www.youtube.com/channel/UCjmwHCZ-qh3ro7hHTQhqYQg)  
  Видео блог компании Флант. Все о Docker и Kubernetes. Очень много суперских докладов и выступлений.

- [ADV-IT](https://www.youtube.com/channel/UC-sAMvDe7gTmBbub-rWljZg)  
  Всё для начинающего и опытного DevOps Инженера, а также уроки по Python.

- [Веб-стандарты](https://www.youtube.com/channel/UCY35dlJe-V5J_IqzU-XksAg)  
  YouTube канал конференции Веб-стандарты — много полезного по веб разработке и не только.
