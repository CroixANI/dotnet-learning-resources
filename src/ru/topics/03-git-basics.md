# Основы системы контроля версий Git

Использование системы контроля версий Git

- [Tproger — Git и GitHub: что это такое и в чём разница](https://tproger.ru/translations/difference-between-git-and-github/)  
  Статья содержащая вводную по системам контроля версий.

- [Tproger — Подробное введение в Git](https://tproger.ru/translations/beginner-git-cheatsheet/)  
  Статья по базовой настройке и командам в Git.

- [Видео-курс — Базовый курс по Git](https://www.youtube.com/playlist?list=PLIU76b8Cjem5B3sufBJ_KFTpKkMEvaTQR)  
  Плейлист с видео уроками по Git.

- [Видео-курс — Git — Полный курс](https://www.youtube.com/playlist?list=PLAma_mKffTOTIomJBmL9J42PP0l7riFUO)  
  Подробный видеокурс по Git от основ до продвинутых тем.

- [Git How To на русском](https://githowto.com/ru)  
  Интерактивный тур, который познакомит вас с основами Git.

- [Learn Git Branching [EN]](https://learngitbranching.js.org/)  
  Интерактивный курс по веткам в Git.

- [Git — учимся работать с правильным workflow](https://monsterlessons.com/project/lessons/git-uchimsya-rabotat-s-pravilnym-workflow)  
  Видео по GitFlow — один из распространенных подходов по веткам, используемым в Git при работе с кодом в компаниях.
